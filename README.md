# AI Civic Complaint Analyzer

## Overview

AI Civic Complaint Analyzer is a Machine Learning and NLP-based platform that helps classify civic complaints, identify priority levels, detect locations, maintain complaint history, and provide analytics through an interactive dashboard.

## Problem Statement

Citizens report complaints related to water, electricity, garbage, roads, traffic, and sanitation. Manual handling of complaints is time-consuming and inefficient.

## Proposed Solution

The platform uses Machine Learning to automatically analyze complaints and provide:

- Complaint Classification
- Confidence Score
- Sentiment Analysis
- Priority Detection
- Location Detection
- Complaint History Storage
- Analytics Dashboard

## Features

### Complaint Classification
Automatically classifies complaints into:
- Water
- Garbage
- Electricity
- Road
- Traffic
- Sanitation

### Confidence Score
Displays prediction confidence percentage.

### Sentiment Analysis
Identifies complaint sentiment.

### Priority Detection
Flags critical complaints as High Priority.

### Location Detection
Detects locations such as:
- Patna
- Kankarbagh
- Danapur
- Gaya
- Muzaffarpur
- Bhagalpur

### Complaint History
Stores analyzed complaints for future reference.

### Analytics Dashboard
Provides:
- Total Complaints
- Unique Categories
- High Priority Complaints
- Category Distribution
- Location Distribution
- Recent Complaints
